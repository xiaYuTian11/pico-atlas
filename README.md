# 小图鉴 · Pico Atlas

> 给 3–5 岁的第一本看图百科。
> 一张图，一个词，一句诗，一个小故事。

---

## 这是什么

**小图鉴**是一款面向 **3–5 岁儿童**的图文启蒙应用。

核心形态是「一页一物」的翻页图鉴：

```
大图  →  中文词  →  英文词  →  短句 / 诗句  →  小故事
```

孩子指着一张图，问「这是啥？」，然后认识它、读出它、记住它。

---

## 内容模块

| 模块 | 内容 | 示例 |
| --- | --- | --- |
| **识物短词** | 水果、蔬菜、动物、日常物品 | 苹果 |
| **中英双语** | 每个词条配英文发音与拼写 | apple |
| **古诗词** | 简短古诗 + 意境插图 | 《咏鹅》 |
| **故事插画** | 小故事 + 连续插画 | — |

四个模块共用同一套「图 + 词 + 音」底层结构，只是承载的文本长度不同。

---

## 目标用户

| 角色 | 说明 |
| --- | --- |
| **使用者** | 3–5 岁儿童 —— 不识字，靠图、靠听、靠点 |
| **决策者** | 家长 —— 决定下载、付费、是否放心让孩子单独玩 |

> 这两者的诉求经常相反：孩子要「大、亮、响、能乱点」，家长要「干净、有营养、别上瘾」。
> 产品设计需要在两者之间取平衡。

## 命名

| | |
| --- | --- |
| 中文名 | **小图鉴** —— 「图鉴」取传统博物学之意（《本草图鉴》《海错图》），一页一图，收罗万物 |
| 英文名 | **Pico Atlas** —— `pico` 取「微小」，`atlas` 即图册 |
| 口头语 | **这是啥？** —— 孩子指着图问的那句话，也是产品的 slogan |
| 标识符 | `pico-atlas` |
