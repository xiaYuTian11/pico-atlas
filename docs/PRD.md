---

## 2. 核心哲学与解决的行业痛点

### 2.1 传统幼儿早教产品的四大顽疾
1. **过度刺激与成瘾机制**：闪烁高饱和色、尖锐电子音、打卡排行与闯关金币，导致幼儿大脑多巴胺神经系统过度疲劳。
2. **商业欺诈与乱扣费陷阱**：页面边缘埋伏横幅广告、诱导付费弹窗、复杂的文字树状导航，3 岁孩子碰一下就跳出应用或误扣话费。
3. **严重脱离幼儿生理发育现实**：
   - 按钮小（<48px）、边缘长压手掌导致整屏死锁；
   - 一秒狂戳屏幕 10 次时音频并发爆音卡死；
   - 缺乏离线英文发音包，导致英文静默不发音；
   - 用 Emoji 占位导致跨端长相怪异，孩子无法辨识具象事物。
4. **点读交互僵化呆板**：
   - 要么每次翻页后都是一片死寂，非要孩子再次去精准戳字才读；
   - 要么无法针对古诗进行单曲循环磨耳朵；
   - 在高铁、睡前等场景下缺乏优雅的静音纯看图模式。

### 2.2 小图鉴的五大底层原则
1. **一页一物，全局双壳**：全 App 只有首页壳与卡片舞台壳，无二级详情页，无外部跳出链接。
2. **五大点读与播放模式完整闭环**：点读、翻页即读、自动巡航连读、单卡循环磨耳朵、静音纯看图，按需无缝切换。
3. **全离线、高音质、有感情**：彻底抛弃机械冰冷的浏览器本地实时 TTS，全量采用**预烘焙（Pre-baked）高保真神经童声与母语标准原音**，纯离线秒开，100% 保证中英双语发音动听温润。
4. **统一水彩绘本插画**：彻底废弃跨端分裂的 Emoji，全库统一为温暖水彩扁平绘本插画，大色块、圆润无尖角、高辨识度。
5. **真正的儿童认知益智**：依托蒙台梭利教具原理与皮亚杰认知理论，设计影子配对、听声辨物、分类归位、手眼轨迹描绘等真益智互动，零挫败无打叉，保护探索天性。

## 3. 核心通用交互底座：五大播放与点读模式矩阵

结合国内外优秀开源启蒙项目（如 GCompris、TouchRead）与顶尖实体点读机（有声挂图、毛毛虫点读笔）的物理直觉，系统底层原生支持 **五大播放与点读模式**：

```
┌─────────────────────────────────────────────────────────────┐
│ 模式 1：翻页即读 (Flip & Read · 默认模式)                     │
│ ➔ 像实体有声翻翻书一样！滑屏或点击 ‹ › 翻到新卡片，落定      │
│   250ms 自动清晰朗读当前卡片双语（中文 + 停0.8s + 英文）。    │
│   无需孩子翻页后再次点击，极大降低认知负荷！                 │
├─────────────────────────────────────────────────────────────┤
│ 模式 2：自由点读 (Tap to Read · 探索模式)                     │
│ ➔ 点哪读哪：点图片发真实拟声/读中文，点英文读标准英文，     │
│   点古诗单句读单句。静默翻页，孩子自由点击探索。             │
├─────────────────────────────────────────────────────────────┤
│ 模式 3：自动巡航连读 (Auto-Play Cruise · 放映机模式)          │
│ ➔ 免操作自动巡航：当前卡片中文×2 ➔ 停顿 ➔ 英文×2 ➔ 停顿 1.2s  │
│   ➔ 平滑自动翻到下一张。适合吃饭、玩玩具时平放磨耳朵。        │
├─────────────────────────────────────────────────────────────┤
│ 模式 4：单卡循环磨耳朵 (Loop & Memorize · 记忆背诵模式)       │
│ ➔ 锁定当前单张卡片或单首古诗（如《咏鹅》《悯农》）循环诵读， │
│   建立平仄韵律肌肉记忆，直到手动点击暂停。                   │
├─────────────────────────────────────────────────────────────┤
│ 模式 5：静音纯看图 (Quiet Book · 护耳静音模式)                │
│ ➔ 一键全局静音：公共场合（高铁、医院、餐厅）或睡前亲子共读，  │
│   由家长亲自讲读，没有任何音频发声。                         │
└─────────────────────────────────────────────────────────────┘
```

## 4. 通用底栏 5 槽控制系统（Standard 5-Slot Bottom Bar）

为保证 3–5 岁幼儿无需识字即可自如掌控所有模式，底栏严格统一为 **标准 5 槽居中布局**：

```
┌──────────────────────────────────────────────────────────────┐
│     ‹          🔁           ▶          ❤️           ›       │
│   (58px)     (48px)       (76px)     (48px)       (58px)     │
│   上一张    模式切换     自动巡航    收藏红心     下一张     │
└──────────────────────────────────────────────────────────────┘
```

1. **中间核心主键 ▶（76px 阳光橙）**：一键开启 / 暂停自动巡航连读，播放时变为暂停方块 ■ 并伴随光晕脉冲；
2. **左右大箭头 ‹ 和 ›（58px 白底圆钮）**：手动翻页，触发“翻页即读”；
3. **左侧辅助槽 🔁（48px 模式切换钮）**：单点循环切换：`翻页即读 🔊` ➔ `单卡循环 🔁` ➔ `自由点读 👆` ➔ `静音纯看图 🔇`，配以极轻声反馈；
4. **右侧辅助槽 ❤️（48px 喜爱红心钮）**：点击弹出小红心粒子，将卡片加入“我的最爱”独立专属分类，满足幼儿强烈的占有欲与收藏成就感。

```
                ┌───────────────────────────────┐
                │ 维度 1：按儿童认知发展里程碑分层│ (脑科学分层)
                └──────────────┬────────────────┘
                               │
 ┌─────────────────────────────┼─────────────────────────────┐
 │                             │                             │
 ▼                             ▼                             ▼
┌──────────────┐      ┌─────────────────┐      ┌─────────────────┐
│ 维度 2       │      │ 维度 3          │      │ 维度 4          │
│ 双角色旅程图 │      │ 三感官交互闭环  │      │ 鲁棒性防御矩阵  │
│ (懂家长与场景)│     │ (视/听/触联动)  │      │ (防崩溃与乱戳)  │
└──────────────┘      └─────────────────┘      └─────────────────┘
```

### 维度 1：儿童认知发育里程碑分层（内容随年龄加深，不重复教学）
- **L1 (3–4 岁 · 感官动作期)**：纯大图 + 拟声词 + 极简中英文词；古诗全诗展示但主读前两句；益智以简单影子与听音为主。注意力窗口 2–3 分钟。
- **L2 (4–5 岁 · 具象表征期)**：同一卡片**长出**拼音与生活化短句描述（≤8 字）；数数感知 1–10；古诗逐句跟读；益智加入颜色大小分类与轨迹描绘。注意力窗口 4–5 分钟。
- **L3 (5–6 岁 · 符号探索期)**：同一卡片**长出**客观小常识（Fact）；整首古诗吟诵与白话浅释；英文简短句子；益智加入视觉闭合与因果常识。注意力窗口 5–8 分钟。

### 维度 2：双角色全生命周期旅程（Dual-Persona Journey）
- **交付环节 (Hand-off)**：秒开进首页；修改年龄设置**长按 3 秒家长闸门**，防止误改。
- **独处探索 (Solo Play)**：**手掌误触免疫**、**狂戳 Cancel-Then-Play**、**弧形低门槛滑动翻页**。
- **亲子共读 (Co-viewing)**：卡片提供浅灰色小知识给家长看；提供隐蔽的**亲子辅读抽屉**（白话背景与提问建议）。
- **温柔收尾 (Exit Ritual)**：**温柔安睡仪式**（达到 15 分钟自动转入护眼深色与晚安动画，禁用翻页）。

### 维度 3：视 · 听 · 触 三感官交互闭环
- **点卡片图片**：缩放回弹 0.94× + 优先播放真实拟声词（猫叫/汽笛）。
- **点中文文字**：发橙色柔光、字重加深 + 朗读中文（0.85× 语速，温暖讲故事音色）。
- **点英文文字**：发纯净蓝光 + 朗读英文单词（0.9× 语速，少儿原声）。
- **益智选择正确**：金色粒子光斑扩散，物体贴合入位 + 欢快拟声与风铃音。
- **益智选择错误**：物体轻微果冻左右晃动 + 柔和水泡音，绝无刺耳警报与红叉。

### 维度 4：系统鲁棒性与异常防御矩阵
- **双手抱屏 / 手掌边缘搭附**：单指优先，触点半径 > 28px 或贴边 < 12px 的长压完全过滤。
- **一秒狂戳 10 次 (Rage Tapping)**：视觉弹性回弹无节流；音频采用 `Cancel-Then-Play`，同元素施加 280ms 最小触发间隔。
- **连读中孩子乱动**：任何手动操作立刻终止自动连读，▶ 恢复初始状态，重置所有高亮。
- **故事阅读中途退出**：故事下次重新进入时，**强制从 Page 1 开始**，保障叙事因果链完整。
- **涂鸦互动与划动翻页冲突**：互动卡片声明 `gestureLock: true`，禁用全屏划动，由底部 ‹ › 按钮控制。

## 7. 技术架构与资产工程管线（全免费高音质落地路线）

> 完整参数表、各分类生图 Prompt 模板与 Python 自动化脚本详见：[`docs/asset-pipeline-spec.md`](asset-pipeline-spec.md)。

### 7.1 语音工程：Edge-TTS 离线预烘焙（100% 免费、高质量、零版权费）
- **核心原理**：利用开源的 `edge-tts`（Python/Node.js 开源工具），直接免费调用微软在大模型边缘节点的真实神经语音（Neural TTS），无需申请付费 Azure API Key，无需信用卡，完全公开可用。
- **推荐音色配置**：
  - **中文发音与故事**：`zh-CN-XiaoxiaoNeural`（温暖生动的亲子讲故事体，富有起伏的情感表达，语速 `rate: -24%`，音调 `pitch: +5Hz`，从容慢速适合幼儿捕捉）；
  - **英文启蒙单词**：`en-US-AnaNeural`（专为少儿启蒙设计的自然美语童音，发音饱满清晰，语速 `rate: -20%`）；
  - **拟声音效**：通过纯离线 Web Audio 实时合成 + 本地无版权高清环境实录音效库（FreeSound CC0 授权）；
- **打包与体积**：开发期通过脚本一键批量下载生成本地 `.mp3` 资源池，全库 500+ 音频深度压缩为 64kbps，总大小 **≤ 12MB**，100% 随应用离线打包，秒开零延迟。

## 8. 红线与绝不做的事

- ❌ 绝对不做任何广告、外链、用户注册、积分排名。
- ❌ 绝对不在主交互区放置需要精细操作的小图标。
- ❌ 绝对不要让任何点击处于"沉默无反馈"状态。
- ❌ 绝对不在生产环境中依赖浏览器不可控的在线实时 TTS。
- ❌ 绝对不做任何带挫败惩罚（扣分打叉）或成瘾诱导的伪益智游戏。
