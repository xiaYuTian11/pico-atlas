# 需求文档（PRD）· 小图鉴 Pico Atlas

## 1. 一句话

给 3–5 岁的**看图百科**：一张图，一个词，一句诗，一个小故事。

（待补充：为什么做这个 App）

## 3. 用户

| 角色 | 说明 |
| --- | --- |
| **使用者** | 3–5 岁儿童。不识字、注意力 3–5 分钟、靠图靠听靠点 |
| **决策者** | 家长。决定下载、付费、是否放心让孩子单独玩 |

**关键约束（CDC 3 岁里程碑建议）：**
> 每天屏幕时间 ≤ 1 小时，且需成人陪同。

因此产品**不做**沉迷设计、不做无限信息流诱导、不做广告。结构越简单，家长越能当"陪伴者"而不是"操作员"。

## 4. 信息架构（已定）

**只有 2 跳。没有第三层，没有详情页。**

```
启动
 ├─ 首次：选年龄（3 个按钮）→ 记住，以后不再问
 │
 └─ 首页（唯一一屏）
     ├─ 🍎 认东西   识物卡片流
     ├─ 📖 读一读   古诗 + 故事卡片流
     └─ 🎨 玩一玩   数数 + 形状 + 涂鸦卡片流
```

### 4.1 核心决策

| 决策 | 内容 | 理由 |
| --- | --- | --- |
| **首页只有 3 个入口** | 认东西 / 读一读 / 玩一玩 | 幼儿工作记忆 3±1；3 岁不会做选择 |
| **分类不进导航** | 水果/动物/电器只是卡片流的**顺序**，不是按钮 | 孩子不按分类找东西，只会滑、点、看 |
| **没有家长模式** | 纯儿童模式 | 避免层级和误操作 |
| **没有"今日"** | 不做内容编排 | 断点续读本身就是"跟着成长" |
| **没有底部导航** | 返回固定左上角 🏠 | 底部是手掌误触重灾区 |
| **全卡片化** | 故事 = 多张连续卡片，古诗 = 1 张卡片 | 只需学一种交互；进度只记一处 |
| **没有详情页** | 长内容拆成多张卡片，用角标标页码 | 3 岁"进得去出不来" |

---

## 5. 三个入口的内容

| 入口 | 卡片流顺序 | 交互 |
| --- | --- | --- |
| **🍎 认东西** | 水果 → 蔬菜 → 动物 → 电器 → 日常 → 玩具 → 衣物 → 交通工具 | 点卡片朗读；连读自动播；左右滑翻页 |
| **📖 读一读** | 古诗（L1 只 1 句）→ 故事（每页一张卡，带页码角标） | 古诗逐句读；故事按页滑 |
| **🎨 玩一玩** | 数数（1–5）→ 形状（圆/方/三角）→ 涂鸦 | 触摸互动，不强制朗读 |

> **识字**不单独开入口。放进「玩一玩」做成"找一样的字"配对游戏。3 岁做识字必须有分寸——做成玩，不做成课。

## 6. 年龄分层（跟随成长）

### 6.1 原则：内容不重复，只加深

同一个物品跨阶段**增加字段**，不重复教学。

> ❌ 3–4 岁学"苹果/apple"，4–5 岁再学一遍
> ✅ 3–4 岁认"苹果/apple"；4–5 岁在同一张卡上多出拼音和例句；5–6 岁再多出汉字和小知识

孩子升一年，**同一批内容会自己"长"出更多字**，感觉是"我认识这个，但多了新东西"。

### 6.2 三档

| 阶段 | 年龄 | 卡片深度 | 单次注意 |
| --- | --- | --- | --- |
| **L1** | 3–4 岁 | 图 + 中文 + 英文 | 3 分钟 |
| **L2** | 4–5 岁 | + 拼音 + 中文短句 + 英文短语 | 5 分钟 |
| **L3** | 5–6 岁 | + 汉字字形 + 英文短句 + 一句小知识 | 8 分钟 |

### 6.3 年龄怎么设

- **首次启动**选一次，存下来，以后不再问
- 首页右上角一行小字显示当前档位，**孩子够不着、点不准**
- 家长点开可改

## 7. 交互规范

### 7.1 手势只有三种

| 手势 | 行为 |
| --- | --- |
| **左右滑** | 上一张 / 下一张 |
| **点卡片** | 朗读当前内容一次（单读） |
| **点 ▶** | 连读：中文 ×2 → 英文 ×2 → 自动翻下一张 |

### 7.2 连读的节奏

```
[中文] 苹果 → 停 0.6s → 苹果
      ↓ 卡片切换为英文（文字变色 + 背景微变）
[英文] apple → 停 0.6s → apple
      ↓ 停 1.2s
[自动翻下一页]
```

**语言切换必须有视觉变化。** 否则 3 岁会把中英文当成四个不同的东西。

### 7.3 返回

固定左上角 🏠，**永远在同一位置**。不做侧滑返回（会误触）。

### 7.4 反馈

- 任何点击必须有即时响应（朗读 / 动效），不能有"点了没反应"
- 触控目标 ≥ 64px

## 8. 状态与持久化（已定）

### 8.1 必须记住

| # | 状态 | 恢复行为 |
| --- | --- | --- |
| 1 | 年龄档 | 直接进首页，不再问 |
| 2 | **每个入口各自的最后位置** | 认东西回第 37 张；读一读回第 2 首；互不覆盖 |
| 3 | 已看过的卡片 | 进度条 |
| 4 | 上次播放模式 | 记住 |
| 5 | 累计使用时长 | 后台记录 |

### 8.2 关键：记 id，不记序号

```
❌ 记"第 37 张" → 以后插入新内容，位置全错
✅ 记 "cat"     → 无论前后加多少内容，永远回到小猫
```

恢复时拿 `lastId` 去当前列表里找；**找不到就从该段开头开始**，不报错、不白屏。

### 8.3 存储位置

| 阶段 | 方案 |
| --- | --- |
| HTML 原型 | `localStorage` |
| App | 本地存储（AsyncStorage / SQLite） |

**不上云、不要账号。** 儿童数据没有上云理由。

### 8.4 边界（第一版不解决）

- **两个孩子**：不做多档案。切年龄时进度保留，二宝会从大宝停下的地方继续
- **清缓存 / 换设备**：进度丢失，不做恢复

详见 [`state-spec.md`](state-spec.md)。

## 9. 内容计划（首期）

| 模块 | 首期量 | 说明 |
| --- | --- | --- |
| 识物 | 100–200 张 | 覆盖水果/蔬菜/动物/电器/日常/玩具/衣物/交通 |
| 古诗 | 10–20 首 | 五言绝句优先，L1 只读 1 句 |
| 故事 | 5–10 个 | 每个 ≤5 页（L1），每页一张卡 |
| 数数 | 1–5 | |
| 形状 | 圆 / 方 / 三角 | |

**选词依据：** 识物优先取 **Dolch Nouns 95 词**（英语启蒙通行标准），再补中国生活场景特有物品。

## 10. 技术决策

| 项 | 决定 |
| --- | --- |
| 原型形态 | **单文件 HTML**，浏览器直接打开 |
| 语音 | **TTS（Web Speech API）**，中文 0.85×、英文 0.9×；后期换真人录音 |
| 插图 | **统一插画风格**；原型阶段用 emoji 占位 |
| 平台 | 待定（先验证交互，再套壳） |
| 离线 | 目标是完全离线可用 |

## 11. 明确不做

- ❌ 广告、外链、社交分享入口
- ❌ 家长模式 / 设置页
- ❌ 底部导航栏
- ❌ 详情页（第三层）
- ❌ 账号、云同步
- ❌ 排行榜、积分、连续打卡（会让 3 岁为奖励而学）
- ❌ 逐字讲解古诗、诗人介绍、创作背景
