# 视觉规范（Design Spec）· 小图鉴 Pico Atlas

针对 3–5 岁。核心一句话：

> **图大、字少、留白多。**
> 不是"图大字小"，是"图大、字少、字照样大"。

---

## 1. 三条硬原则

### 1.1 图是主体，但不要占满

| 图片占卡片 | 效果 |
| --- | --- |
| < 40% | 小气，看不清 |
| **70–85%** | ✅ 有聚焦、有呼吸 |
| > 90% | ❌ 失去边界感，孩子不知道看哪 |

孩子需要**留白衬托物体**。挤满全屏反而降低识别率。

### 1.2 文字不能小，只能少

| 事实 | 后果 |
| --- | --- |
| 3–5 岁视力约 0.6–0.8 | 同一行字需要比成人**大 1.5 倍** |
| 幼儿对细小元素不敏感 | 小字等于不存在 |

```
❌ 小字多写：苹果 48px / píng guǒ 18px / apple 22px / 红红的苹果 16px
✅ 少字大字：苹果 56px / apple 30px
```

**是砍字数，不是砍字号。**

### 1.3 一屏一个焦点

不做九宫格、不做多卡片并排、不加装饰插画和花纹。背景纯色或极浅色。

---

## 2. 布局规则（硬性）

### 2.1 屏幕分区（固定高度，永不变动）

```
┌─────────────────────────────┐
│ 顶栏            56px          │  🏠 + 进度条 + 计数
├─────────────────────────────┤
│                             │
│         卡片区               │  ← 占据剩余全部高度
│                             │
│   ┌───────────────────┐     │
│   │   图片区  flex:1   │     │  ← 吃掉所有剩余空间
│   ├───────────────────┤     │
│   │  文字区  flex:0 0 auto │  ← 按内容高度，不用固定比例
│   └───────────────────┘     │
│                             │
├─────────────────────────────┤
│ 控制栏          88px          │  ‹  ▶  ›
├─────────────────────────────┤
│ 安全区 env(safe-area-inset)  │
└─────────────────────────────┘
```

### 2.2 铁律（这几条是踩过坑的）

| # | 规则 | 原因 |
| --- | --- | --- |
| 1 | **图片区 `flex:1`，文字区 `flex:0 0 auto`** | 绝不用 `flex:65 / flex:35` 这种写法 —— 一旦写成 `flex:65` / `flex:1`，文字区只剩 1.5% 高度，立刻溢出遮挡 |
| 2 | **主体尺寸由 JS 实测容器计算** | 不写死 `vh`。`fontSize = min(区高, 区宽) × 0.86`，保证任何屏幕、任何 emoji 字形都不溢出 |
| 3 | **文字区不设 `overflow:hidden`** | 隐藏溢出会把文字静默裁掉，用户看不到还以为没写。要么放得下，要么缩小字号 |
| 4 | **不允许绝对定位的浮动内容** | 只允许角标（故事页码）用 `position:absolute`，且固定在小角落 |
| 5 | **文字区 `z-index` 高于图片区** | 万一将来有溢出，也是图被遮，不是文字被遮 |

### 2.3 主体尺寸计算公式

```js
const picArea = document.querySelector('.pic-area');
const h = picArea.clientHeight - 24;   // 扣内边距
const w = picArea.clientWidth  - 24;
const fontSize = Math.max(56, Math.min(h * 0.86, w * 0.86));
```

`0.86` 是安全系数：emoji 字形实际高度约为字号的 1.05–1.25 倍，留 14% 余量保证不裁切。

## 3. 各内容类型的图文占比（实测值）

因为文字区按内容自适应，实际占比会随类型变化。**这是想要的效果**——文字多的内容自动给图少一点空间。

| 类型 | 图片区 | 文字区 | 说明 |
| --- | --- | --- | --- |
| **识物** object | ~80% | ~20% | 两个字，图最大 |
| **数数** number | ~75% | ~25% | 物品阵列 + 大数字 |
| **形状** shape | ~78% | ~22% | 单个几何图形 |
| **故事** story | ~72% | ~28% | 标题 + 一行文字 |
| **古诗** poem | ~55% | ~45% | 诗句要占空间，图必须让位 |

> 古诗是最容易被忽略的：它虽然也是"卡片"，但文字比识物多 4 倍，**必须单独降低图片比例**，否则诗句会被图盖住。

## 4. 字号表

| 元素 | L1（3–4） | L2（4–5） | L3（5–6） | 备注 |
| --- | --- | --- | --- | --- |
| 中文词 | 56px | 52px | 48px | 加粗 800，字距 2px |
| 拼音 | — 不显示 | 20px | 18px | 常规，低对比 |
| 英文词 | 30px | 28px | 26px | 加粗 700 |
| 中文短句 | — | 22px | 20px | 常规 |
| 英文短句 | — | 22px | 20px | 加粗 600 |
| 小知识 | — | — | 18px | 最弱 |
| 古诗正文 | 30px | 28px | 26px | 加粗 700，字距 3px |
| 故事正文 | 28px | 26px | 24px | 加粗 700 |
| 大数字 | 104px | 104px | 96px | 超粗，主色 |

**绝对下限：任何给孩子看的文字不小于 18px。**

**L1 一律不显示拼音。** 3 岁不看拼音，多了只是噪音。

## 5. 颜色

### 5.1 文字对比

| 元素 | 色值 | 说明 |
| --- | --- | --- |
| 中文 | `#2E2A26` | 近黑，主信息最清楚 |
| 英文 | `#3C7DD9` | 中蓝，次信息也要清楚 |
| 拼音 | `#8A8178` | 浅灰，辅助可弱 |
| 句子 | `#8A8178` | 家长读，可弱 |
| 小知识 | `#B9AFA4` | 最弱 |

**中文和英文都必须够清楚**——它们都是要学的内容。只有拼音和句子可以弱化，因为它们只是拐棍。

### 5.2 品牌与背景

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#FDF8F3` 暖米白 |
| 卡片背景 | 每个词条自带 `palette`，与主色协调 |
| 主色（按钮/强调） | `#F5904A` 暖橙 |
| 分割线 | `#EFE6DC` |

### 5.3 卡片底色

每个词条配一个与该物品主色协调的浅色底（如苹果 `#FFF1E8`、葡萄 `#F3EEFB`）。
**饱和度要低**，只作氛围，不能抢主体。

## 6. 触摸与反馈

| 项 | 规范 |
| --- | --- |
| 最小触控目标 | **64 × 64 px** |
| 图标按钮 | ≥ 44px |
| 主按钮（▶） | 74px |
| 点击反馈 | 缩放到 0.93~0.94，`cubic-bezier(.34,1.56,.64,1)` |
| 播放中状态 | 按钮脉冲发光，图标变 □ |
| 静默 | **不允许**——点了必须有声或有动效 |

---

## 7. 位置稳定（3 岁靠位置记忆，不靠认字）

```
🏠 永远左上角          年龄标签 永远右上角（小字）
进度条 永远顶部
‹ ▶ ›  永远底部中间
```

**这些位置一次都不能挪。** 孩子是靠"东西在哪儿"来操作的，挪一次就要重新学。

---

## 8. 动效

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 翻页 | 300ms | ease-out |
| 卡片底色切换 | 350ms | ease |
| 点击缩放 | 180ms | cubic-bezier(.34,1.56,.64,1) |
| 语言切换高亮 | 220ms | ease |

**不要花哨动效。** 3 岁注意力会被任何移动的东西吸走，动效只用于"说明刚刚发生了什么"。

---

## 9. 图片素材规范

| 项 | 规范 |
| --- | --- |
| 风格 | **全库统一插画风格**（不做照片与插画混用） |
| 格式 | WebP，单图 ≤ 200KB |
| 尺寸 | 长边 1024px |
| 背景 | 透明或纯色，主体占画面 ≥ 60% |
| 视角 | 正面平视为主，避免透视变形 |
| 数量 | 一张卡片只放一个主体 |

**原型阶段用 emoji 占位**。注意：不同 emoji 的字形大小差异很大（🦢 比 🥕 大一圈），所以主体尺寸必须动态计算，不能统一写死。

---

## 10. 反面清单

- ❌ 用 `flex:65` / `flex:1` 做分栏（文字区会被压没）
- ❌ 写死 `vh` 作为主体字号（不同 emoji、不同屏幕会溢出）
- ❌ 给文字区加 `overflow:hidden`（静默裁掉文字）
- ❌ 小字号（< 18px）
- ❌ 九宫格 / 多卡片并排
- ❌ 装饰花纹、渐变背景、水印
- ❌ 底部导航栏
- ❌ 需要精确点击的小角标
- ❌ 自动播放的动画视频
- ❌ 超过 3 种颜色同时出现
- ❌ 任何需要识字才能操作的界面
