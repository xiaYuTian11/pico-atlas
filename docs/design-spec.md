# 视觉与布局规范（Design Spec）· 小图鉴 Pico Atlas

> 版本：**v2.1 — 统一跨端布局、标准 5 槽底栏控制系统与全套模式视觉契约**  
> 目标人群：3–5 岁幼儿（视力 0.6–0.8，手部精细动作发育中，靠图、听、触）与陪同家长  
> 核心哲学：**图大、字少、留白多；全诗意境，骨架统一；模式清晰，自如掌控。**

## 2. 响应式视口系统（跨终端适配）

### 2.1 视口断点形态

| 模式 | 判定条件 | 布局形态 | 控制与交互位置 |
| :--- | :--- | :--- | :--- |
| **手机竖屏 (Mobile Portrait)** | 宽度 < 600px 且 竖屏 | 单列垂直堆叠：上图下文 | 底部居中 5 槽控制条 |
| **平板竖屏 (Tablet Portrait)** | 宽度 ≥ 600px 且 宽高比 < 1.1 | 居中卡片舞台（最大宽度 580px），两侧自然留白 | 底部居中 5 槽控制条，触控等比放大 |
| **横屏模式 (Landscape Split)** | 宽度 ≥ 640px 且 宽度 > 高度 | **左右分栏舞台**：<br>左侧 52% 视觉区，右侧 48% 文本区 | 顶栏左上角 🏠；底栏居中舒适区 |

│                             │                             │

## 3. 标准 5 槽底栏控制系统规范 (Standard 5-Slot Bottom Bar)

为了满足幼儿“翻页即读、自动巡航、循环磨耳朵、收藏红心”等全套高频需求，底栏固定为 **五槽居中标准布局**：

```
┌──────────────────────────────────────────────────────────────────────────────┐
│       Slot 1           Slot 2           Slot 3          Slot 4        Slot 5 │
│        ‹ 上页          🔁 模式切换       ▶ 自动巡航       ❤️ 收藏红心    › 下页  │
│        (58px)           (48px)          (76px)          (48px)        (58px) │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 3.1 五大槽位参数与触控规范

| 槽位 | 默认尺寸 | 视觉外观 | 状态定义与动效 | 交互职责 |
| :--- | :--- | :--- | :--- | :--- |
| **Slot 1 (左外)** | `58 × 58 px` | 白底圆钮，深灰箭头 `‹` | 激活缩放 0.92×，首张时置灰不可点 | 手动翻到上一张（落定后触发当前模式规则） |
| **Slot 2 (左内)** | `48 × 48 px` | 暖米灰底圆钮 `#F4ECE4` | 单击循环切换 4 态图标：<br>• `🔊 翻页即读` (默认)<br>• `🔁 单卡循环`<br>• `👆 自由点读`<br>• `🔇 静音纯看` | 播放模式切换，伴随柔和水泡音，文字轻 Toast 提示当前模式 |
| **Slot 3 (核心中)**| `76 × 76 px` | 阳光橙底圆钮 `#F5904A`，白色主图标 | • 静止态：显示 `▶`，阴影沉稳<br>• 播放中：显示 `■`，外环连续呼吸光晕脉冲 (周期 1.4s) | 一键开启 / 暂停自动巡航连读（高优先级打断） |
| **Slot 4 (右内)** | `48 × 48 px` | 暖米灰底圆钮 `#F4ECE4` | • 未收藏：显示浅灰空心 `🤍`<br>• 已收藏：显示鲜红实心 `❤️`，点击弹出 3 颗微型红心向上漂浮渐隐 | 将卡片加入“我的最爱”独立分类，满足幼儿占有与收藏感 |
| **Slot 5 (右外)** | `58 × 58 px` | 白底圆钮，深灰箭头 `›` | 激活缩放 0.92×，末张时置灰不可点 | 手动翻到下一张（落定后触发当前模式规则） |

## 4. 通用卡片三插槽契约 (Universal Three-Slot Contract)

所有卡片模块（识物、古诗、故事、益智）必须严格遵守三插槽结构：

```html
<div class="pa-card">
  <!-- Slot A: 辅助信息插槽（页码角标、朝代作者、益智分类标识、亲子小灯泡） -->
  <div class="pa-card-header">...</div>

  <!-- Slot B: 视觉主体插槽（flex: 1 居中绘本大图/SVG/数数阵列/画布/益智操作盘） -->
  <div class="pa-card-visual">...</div>

  <!-- Slot C: 声文与释义插槽（flex: 0 0 auto 自底向上排列） -->
  <div class="pa-card-content">...</div>
</div>
```

## 5. 各内容类型在三插槽中的版面表现

### 5.1 识物卡片（Object）
- **Slot B**：单件主体居中，视觉占比最高（约 70%~75%）。
- **Slot C**：
  - L1：主中文大字（56px）+ 英文次大字（30px）。
  - L2：加入拼音（20px）与中文短句（22px）。
  - L3：加入小百科常识（18px）。

### 5.2 古诗卡片（Poem）—— 全诗 20 字优雅排版
- **四句整齐排列**：五言绝句居中对称排版，单字字号 **28–30px**（加粗 800），字距 `4px`，行距 `12px`；
- **分句点读交互**：每一句都是一个大触控条（高度 ≥ 44px），手指点到哪一句，哪一句文字发橙色柔光并微缩回弹，播放该句发音；
- **音画同步（Karaoke 流）**：朗诵到哪一句，哪一句发橙色光高亮，其余句子半透明弱化（`opacity: 0.5`）。

### 5.3 故事卡片（Story）与终章全景画卷 (Recap)
- **常规页（Page 1 ~ N-1）**：
  - Slot A：固定胶囊角标 `小兔子找妈妈 · 1 / 4`；
  - Slot B：连续绘本插画（占 60%）；
  - Slot C：故事主短句（26–28px，最多 2 行）。
- **终章页（Page N · 故事画卷）**：
  - 故事最后一页在 Slot C 底部展开 **四格缩略连环画胶囊**，直观展现故事的起承转合，点击可重播整篇。

### 5.4 玩一玩：益智游戏卡片
- **影子剪影配对**：上方黑色剪影框，下方并排 3 个候选大按钮；
- **听声辨物寻踪**：中央大喇叭发声按钮（带声波扩散光环），下方 3 张大图；
- **大小颜色分类**：上方左右两个收纳篮，下方待分类物品；
- **手眼轨迹描绘**：发光粗虚线轨迹，声明 `gestureLock: true`，独占触摸。

## 6. 音画同步与感官动效矩阵 (Karaoke & Sensory Matrix)

| 触发场景 | 视觉反馈 (See) | 听觉反馈 (Hear) | 动效参数 (Feel) |
| :--- | :--- | :--- | :--- |
| **翻页即读触发** | 卡片落定 250ms 后，中文先亮起 ➔ 英文亮起 | 依次播放中文名称与英文单词（间隔 0.8s） | 250ms 平滑渐变高亮 |
| **点卡片图片/Emoji** | 图片缩放至 0.94，产生轻微弹跳 | 优先播放真实音效/拟声词（猫叫/汽笛） | 180ms, `cubic-bezier(.34,1.56,.64,1)` |
| **点中文文本** | 文字字重加深、发橙色微光 | 朗读中文发音（0.85× 语速童声） | 150ms 弹性下凹 |
| **点英文文本** | 文字发纯净蓝光脉冲 | 朗读英文单词（0.9× 语速少儿原声） | 150ms 弹性下凹 |
| **点播放键 ▶** | 按钮变暂停方块 ■，外环呼吸光晕 | 启动自动巡航连读 | 连续光晕脉冲，周期 1.4s |
| **收藏小红心点击** | 🤍 变 ❤️，缩放 1.3x 回弹，冒出 3 颗小红心 | 悦耳叮咚微风铃音 | 380ms 浮动渐隐 |
| **益智选择正确** | 金色粒子光斑扩散，物体贴合入位 | 欢快拟声词 + 悦耳叮咚声 | 弹性贴合回弹 220ms |
| **益智选择错误** | 物体轻微果冻左右摇摆 (±6px) | 柔和水泡音 `pop`，绝无刺耳警报 | 弹性果冻摆动 180ms |

## 7. 亲子辅读抽屉规范 (Parent Drawer)

- **唤出入口**：Slot A 右上角淡灰色灵感小灯泡（💡）图标，或卡片底部双指轻微上滑；
- **抽屉视觉**：从屏幕底部平滑升起（高 46%，圆角 28px，淡米白背景 `#FFFDF9`，带遮罩）；
- **内容构成**：
  1. 通俗白话故事（100 字以内生动译文，供家长念读）；
  2. 亲子互动提问建议（如：“问问宝宝大白鹅红红的脚掌怎么划水的呀？”）；
- 点击空白遮罩即刻收起，不影响主卡片流。
