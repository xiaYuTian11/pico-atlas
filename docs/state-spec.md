# 状态与交互状态机规范（State Spec）· 小图鉴 Pico Atlas

> 版本：**v2.1 — 统一交互状态机、五大播放模式流转与收藏持久化契约**  
> 目标：系统化定义全 App 统一的**手势过滤、五大播放模式状态机、翻页即读防抖、收藏状态与数据记忆**。

## 1. 全局架构：三层状态模型

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 运行时手势与触控状态机 (Interaction State Machine)         │
│    - 掌压与边缘误触过滤 (Palm & Edge Rejection)              │
│    - 弧形低门槛滑动判定 (Smart Swipe Classifier)            │
│    - 互动卡片手势锁 (Gesture Lock for Play)                  │
├─────────────────────────────────────────────────────────────┤
│ 2. 五大播放模式状态机 (PlayMode & Audio State Machine)        │
│    - 翻页即读 (flip_and_read) / 自由点读 (tap_to_read)        │
│    - 自动巡航 (auto_cruise) / 循环磨耳朵 (single_loop)       │
│    - 静音纯看 (quiet_mute)                                    │
│    - 强打断调度 (Cancel-Then-Play / Preemption)               │
├─────────────────────────────────────────────────────────────┤
│ 3. 持久化数据状态 (Persistence State - 本地存储)              │
│    - 年龄档、各入口独立断点、收藏列表(favorites)、防沉迷时长 │
└─────────────────────────────────────────────────────────────┘
```

## 2. 五大播放模式状态机 (PlayMode State Machine)

系统维护一个核心运行时枚举 `currentPlayMode`：

```typescript
type PlayMode =
  | 'flip_and_read' // 翻页即读 (默认物理挂图模式)
  | 'tap_to_read' // 自由点读 (不翻不读，点哪读哪)
  | 'auto_cruise' // 自动巡航 (放映机免操作自动翻页)
  | 'single_loop' // 循环磨耳朵 (单卡单诗持续重复背诵)
  | 'quiet_mute'; // 静音纯看图 (无声静心)
```

### 2.1 状态流转与事件驱动矩阵

```
                  ┌──────────────────────┐
                  │ 翻页动作 (Flip Step) │
                  └──────────┬───────────┘
                             │
            ┌────────────────┼────────────────┐
            ▼                ▼                ▼
    [flip_and_read]    [single_loop]    [quiet_mute]
            │                │                │
     落定延时 250ms    循环播读当前卡片   静音，仅文字
            ▼                ▼          高亮或静止
   自动朗读双语一次      停1.5s 再次重复
   (中 ➔ 停0.8s ➔ 英)
```

| 播放模式                                 | 翻页时行为                                                                  | 播放结束时行为                                                     | 手动点击卡片时行为                               |
| :--------------------------------------- | :-------------------------------------------------------------------------- | :----------------------------------------------------------------- | :----------------------------------------------- |
| **`flip_and_read`<br>(翻页即读 · 默认)** | 卡片切换落定后延时 250ms，自动清晰朗读当前卡片双语（中文 + 停 0.8s + 英文） | 朗读完毕后保持静止，等待下一次操作                                 | 掐断当前发音，立即重新单读被点击部分             |
| **`tap_to_read`<br>(自由点读)**          | 静默翻页，没有任何发音                                                      | 保持静止                                                           | 点哪读哪（点图播拟声，点字读中英文）             |
| **`auto_cruise`<br>(自动巡航)**          | 落定后自动读双语两遍                                                        | 停顿 1.2 秒后，自动触发 `stepCard(1)` 平滑翻向下一页；末页自动停止 | 手动触摸卡片或按钮**立即打断巡航**，恢复为静止态 |
| **`single_loop`<br>(单卡循环磨耳朵)**    | 落定后自动朗读全诗或双语词                                                  | 停顿 1.5 秒后，自动重新朗诵本张卡片，无限循环                      | 点击卡片重置本轮循环发音                         |
| **`quiet_mute`<br>(静音纯看图)**         | 静默翻页，不调用任何音频 API                                                | 保持静止                                                           | 仅触发视觉弹性回弹，不发声                       |

### 2.2 模式切换触发逻辑 (Slot 2 按钮)

点击底栏 Slot 2 模式按钮时，按如下顺序顺次循环：
`flip_and_read 🔊` ➔ `single_loop 🔁` ➔ `tap_to_read 👆` ➔ `quiet_mute 🔇` ➔ `flip_and_read 🔊`。  
每次切换伴随柔和水泡音，并弹出 1.2 秒的轻 Toast 提示当前模式名称。

## 3. 手势判定与容错调度算法

### 3.1 掌压与多指误触过滤 (Palm Rejection)

```
[touchstart 事件]
  ├─ 1. e.touches.length > 1 (多指触碰) ─────────────► 丢弃
  ├─ 2. t.radiusX > 28 或 radiusY > 28 (大肉垫/掌触) ──► 丢弃
  ├─ 3. t.clientX < 12px 或 > (window.innerWidth - 12) ──► 贴边握持丢弃
  └─ 4. 单指有效触碰 ────────────────────────────────► 记录起点 (startX, startY, startTime)
```

### 3.2 幼儿低门槛滑动手势判定 (Smart Swipe)

- **有效水平位移门槛**：`|dx| >= 35px`；
- **方向判定角度**：`|dx| > 0.8 * |dy|`（允许 40° 斜向滑动）；
- **超时保护**：划屏耗时 `dt < 650ms`；
- **跟手位移与回弹**：
  - 滑动中：卡片以 `0.65` 阻尼系数跟随手指平移；
  - 达到阈值：280ms 平滑滑出，新卡片滑入；
  - 未达阈值：200ms 弹性回弹归位至 `0px`，绝不卡在半截。

### 3.3 互动卡片手势锁 (Gesture Lock)

- 当卡片声明 `gestureLock: true`（如涂鸦画板、轨迹描绘），全局滑动调度器在此卡片上**完全禁用滑动手势**，触摸事件由画布独占；翻页通过底栏 ‹ 和 › 按钮进行。

## 4. 强打断机制与音频并发调度 (Preemption Protocol)

在任何正在播放音频（无论连读、翻页即读、单卡循环）的过程中，孩子或家长发生以下任何操作，调度器**必须在 1 帧内原子级终止当前音频流程**：

1. 点击底栏 ‹ 上一页或 › 下一页；
2. 手指划动翻页；
3. 点击左上角 🏠 返回首页；
4. 点击底栏 ▶ 暂停按钮；
5. 点击底栏 🔁 切换模式或 ❤️ 收藏；
6. 页面切换入后台或锁屏（`visibilitychange`）。

**打断动作断言**：

- 立即清除所有待执行的 `setTimeout` 定时器；
- 立即调用音频停止接口并重置 Web Speech / Web Audio；
- ▶ 按钮立刻恢复为初始静止态；
- 清除界面上所有的音画同步高亮与遮罩弱化。

## 5. 收藏体系状态机 (Favorites State Machine)

为满足幼儿的收集与占有欲，系统维护全局卡片收藏状态：

```typescript
// 状态集合中增加 favorites 数组
interface FavoritesState {
  favorites: string[]; // 存储卡片 id 集合，如 ["cat", "apple", "t-rex"]
}
```

### 5.1 收藏交互流转

```
[点击底栏 Slot 4 红心按钮]
  │
  ├─ 该卡片未收藏 (🤍) ──► 变 ❤️，加入 S.favorites 数组，冒出红心微粒子，播放清脆风铃音
  │
  └─ 该卡片已收藏 (❤️) ──► 变 🤍，从 S.favorites 中移除，播放水泡消解音
```

### 5.2 首页动态入口规则

- 当 `S.favorites.length > 0` 时：首页动态展现 **“❤️ 我的最爱”** 入口胶囊，显示收藏卡片总数；
- 点击进入后，形成由孩子喜爱的卡片组成的专属卡片流，支持常规的翻页、点读与巡航。

## 7. 异常防御清单 (Robustness Checklist)

- [ ] **连读与翻页即读防抖**：快速连续翻 5 页，中间页面的发音定时器全部被成功取消，只朗读最终落定的一页。
- [ ] **模式记忆**：用户选定“单卡循环”或“静音”后，退出应用重进，模式偏好依然保持。
- [ ] **收藏即时同步**：在卡片舞台点亮红心后返回首页，我的最爱计数立即准确刷新。
- [ ] **故事 Page 1 独立复位**：读到故事第 3 页退出，重进该故事时严格从第 1 页开始。
- [ ] **多指防误触**：两根手指同时接触屏幕，不会触发多余翻页。
